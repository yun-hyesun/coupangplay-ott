쿠팡플레이 회차별 리뷰 / 세션별 채팅 구현

[수정]
page/detail/Detail.jsx : 회차별 리뷰 Firestore 구독, 저장/수정/삭제 연결
page/detail/DetailComponents.jsx : 기존 리뷰 팝업에 작성/수정/삭제, 평점, 스포일러 체크 연결
page/watch/Watch.jsx : 세션 생성/참여, 실시간 메시지 구독/전송, 초대 링크 복사

[추가]
data/communityData.js : ID 및 표시용 데이터 헬퍼
service/reviewService.js : 리뷰 CRUD + onSnapshot
service/sessionService.js : 시청 세션 생성/참여/종료 API
service/chatService.js : 채팅 전송 + onSnapshot
firebase/firestore.rules : 신규 커뮤니티 컬렉션용 보안 규칙 예시

[변경하지 않음]
기존 firebase/firebase.js, 모든 SCSS, Header/Footer/MainLayout, 기타 소스.

[Firebase 설정]
1. 기존 .env의 VITE_FIREBASE_* 설정을 확인하고 Firebase Authentication 로그인 활성화.
2. Firestore 데이터베이스 생성 및 접근 권한 설정.
3. firebase/firestore.rules는 기존 규칙을 덮어쓰면 다른 기능이 중단될 수 있으므로,
   반드시 기존 Firestore Rules와 병합해 콘솔에서 검증한 후 배포하세요.
4. 같은 작품/시즌/회차의 리뷰는 동일 컬렉션에 저장됩니다.
5. Watch의 '같이 보기' 버튼으로 로그인 사용자가 세션을 생성합니다.
   '세션 초대 링크 복사'로 ?session=<id> URL을 공유하고,
   참여자는 해당 URL에서 '같이 보기'를 눌러 같은 채팅방에 들어갑니다.
6. 세션은 같이 보기 OFF로 전환해도 종료하지 않습니다(재참여 가능).
   세션 종료는 service/sessionService.js의 endWatchSession() API를
   호스트가 별도 UI에서 호출하도록 추후 연결할 수 있습니다.
7. 현재 채팅은 최근 50개 메시지만 구독합니다. 과거 기록 추가 조회는 추후 기능입니다.
8. Firestore 읽기/쓰기 사용량에 따라 비용이 발생할 수 있습니다.

[테스트]
- 사용자 A 로그인: 회차 리뷰 작성 → 새로고침 → 기록 확인
- 사용자 B 로그인: 동일 회차 리뷰 확인 / A 리뷰 수정·삭제 시도 차단
- 사용자 A Watch: 같이 보기 ON → 초대 링크 복사
- 사용자 B: 초대 URL 접속 → 같이 보기 ON → 메시지 실시간 확인
- 로그인하지 않은 사용자: 리뷰 작성/채팅 전송 제한
- 다른 세션의 메시지 조회 제한

[주의]
현재 소스 ZIP에는 package.json, node_modules가 없어 npm build 및 실제 Firebase 연결
검증은 수행하지 못했습니다. ZIP 구조 및 변경 파일만 검증했습니다.
기존 리뷰 UI의 '좋아요'는 읽기 전용이며 별도 좋아요 쓰기 API는 없습니다.
실제 서비스 운영 전 스팸 방지, 신고, 보관 기간, 페이지네이션, 테스트가 필요합니다.
