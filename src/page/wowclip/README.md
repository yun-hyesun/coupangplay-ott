# 와우클립

진입 경로: `/wowclip`. 기존 `MainLayout`의 헤더·푸터를 재사용한다. `App.jsx`의 import/Route 두 줄과 `Watch.jsx`의 원본용 가위 버튼을 연결했다. 원본 YouTube의 기본 조작부를 숨기고 기존 시청 화면의 재생·탐색·음량·속도 조작이 YouTube에도 작동하도록 연결했다. 메인에는 `WowClipSection`을 지금 주목받는 영화 다음에 연결했다. 공용 콘텐츠 컴포넌트, 기존 Zustand 저장소, Firebase 설정·규칙, 의존성 파일은 변경하지 않는다.

## 데이터

- 초기 클립·작성자·댓글·공감 데이터는 없다. 사용자가 직접 저장한 클립만 표시한다.
- 클립 목록·감상에는 제작 버튼을 두지 않는다. 원본 `/watch/:type/:id`의 가위 버튼에서만 편집을 연다.
- 영상 정보는 기존 시청 화면의 TMDB/YouTube 결과를 넘겨받는다. 이미지 URL은 API가 반환한 작품 경로와 영상 키에서 만든다. Figma의 예시 작품 이미지와 문구는 넣지 않는다.
- `ClipPlayer`는 기존 설치된 `react-youtube`를 사용한다. 구간 재생은 실제 플레이어의 시각을 읽고 선택 종료 시점에 정지한다. TMDB 공개 영상의 구간 참조를 저장하며 별도 동영상 파일을 인코딩하거나 OTT 본편을 다운로드하지 않는다.
- 클립·댓글·공감은 이 브라우저의 `localStorage['coupangplay.wowclip.v1']`에 저장한다. 로그인 계정·선택 프로필 ID를 소유자 키로 사용하며 비로그인 작업은 별도 local/default 키를 쓴다. 실제 인증 권한을 대신하는 서버 기능은 아니다.
- 현재 복사 링크는 같은 브라우저 저장소에 있는 클립을 연다. 다른 브라우저·기기 공유 및 전체 사용자 공개 목록은 클립 서버 API 연결이 필요하다. 팀 Firebase 컬렉션이나 보안 규칙을 임의로 추가·배포하지 않았다.

## 구조

- `WowClip.jsx`: 목록/내 클립/감상 경로, 스포일러 확인, 삭제, 복사 피드백
- `../home/components/WowClipSection.jsx`: 최종 메인 `5036:75798`의 함께 나누는 와우 클립. 실제 공개 클립을 공감·최신순으로 최대4개 표시하고 카드/전체 보기를 기존 경로로 연결한다. 링크 전용은 제외하며 빈 목록·저장소 오류를 처리한다. 카드와 제목 컴포넌트를 재사용하고 신규 스타일은 해당 섹션에 한정한다.
- `FullVideoClipButton.jsx`: 원본 플레이어의 현재 재생 시각·길이 전달 및 제작 후 감상 이동
- `ClipEditor.jsx`: 원본의 현재 시점 주변 구간, 핸들·방향키 조절과 영상 seek 동기화, 이동을 마치면 선택한 시작점부터 구간 재생, 제목·범위·보호 설정
- `ClipPlayer.jsx`: 공개 YouTube 영상 재생, 탐색·음량·속도·전체 화면
- `ClipComments.jsx`: 사용자 요청에 따라 대기·포커스·작성 중 모두 72px 고정. 16/24 글자·흰색 2px 안쪽 포커스. Enter 등록, Shift+Enter 줄바꿈, Esc 취소. 한글 조합 중 Enter는 등록하지 않는다. 별도 입력 도구행은 두지 않는다.
- 댓글·답글은 같은 하단 입력창을 사용한다. 답글 등록에 성공하면 자동으로 일반 댓글 작성으로 돌아간다. 답글 버튼은 횟수 제한 없이 다시 사용할 수 있으며, 답글의 답글도 같은 원댓글 아래 한 단계로 묶는다. 대화 연결선과 보기·접기를 제공한다. 두 열 화면에서는 댓글 패널을 옆 영상·정보 영역 높이에 맞추고, 답글의 내용이 바깥 레이아웃 높이를 늘리지 않도록 크기 계산을 분리했다. 한 열의 좁은 화면에서는 420px이며 목록 안에서만 스크롤한다.
- 댓글 좋아요 숫자는 같은 폭의 숫자와 최소 두 자리 영역을 사용한다. 자릿수가 늘어나는 토글도 클릭 전후 중 큰 집계값의 폭을 미리 확보해 답글 버튼 위치가 움직이지 않는다.
- 댓글 공감은 18px 엄지의 선/채움으로 표시하며 선택 배경을 만들지 않는다. 클립 공감은 24px 하트의 선/채움, 링크는 실가시 크기를 맞춘 32px 슬롯(버튼 44px)이다.
- 편집 제목 라벨은 `클립 제목`이다. 스포일러 보호를 켠 클립은 목록과 직접 링크 진입에서 확인 팝업을 먼저 표시하고, 열기를 확인하기 전에는 플레이어·제목·댓글을 렌더링하지 않는다. 제작 직후의 본인 확인 화면은 바로 열고, 같은 페이지에서 한 번 확인한 클립은 다시 묻지 않는다.
- 보호 카드의 작품 이미지가 없으면 빈 보호 배경을 사용한다. 클립 장면 썸네일로 대체하지 않는다.
- `clipTimeline.js` / `clipTimeline.test.js`: 원본 시각 기준 범위 계산·경계 제한·전체 구간 이동 및 검증
- `useWowClipLibrary.js`: 빈 초기 상태, 검증·저장·오류·다른 탭 변경 수신
- `wowClipData.js`: API 데이터 표시 및 클립 구간 메타데이터 생성
- `WowClipUi.jsx` / `WowClip.scss`: 와우클립에 한정한 UI와 스타일. 기존 시청 아이콘 및 전용 SVG·벡터 재사용
