# 스포츠 동영상·경기 정보 조회 복구

확인한 오류: YouTube `search.list`가 HTTP 429, `rateLimitExceeded`, 일일 Search Queries 한도 초과를 반환했다. 같은 키의 `channels.list`는 정상 응답했다.

## 변경

- 검색 조회 제한은 429로 구분한다. 제한 시 공식 채널의 `contentDetails.relatedPlaylists.uploads`와 `playlistItems.list`로 전환한다. 재시도마다 제한된 검색을 반복하지 않도록 일정 시간 업로드 목록을 재사용한다.
- 업로드 목록도 기존 공식 채널 검증·리그/팀/한국 월 경계 필터·일반 영상 판별을 적용한다. 쇼츠 및 판별 불가 영상은 계속 제외한다.
- 업로드 목록의 페이지는 리그·팀 간에 공유하며, 검색 커서와 업로드 커서를 구분한다. 월보다 오래된 목록에 도달하면 탐색을 끝낸다.
- 유럽 주요 리그의 라운드 메타데이터와 경기 일정은 동일한 시즌 조회를 공유한다. 동영상 탭에서는 홈의 일정·중계·순위 요청을 실행하지 않는다. 라운드 선택은 이미 받은 영상을 필터링하며 동영상 API를 다시 호출하지 않는다.
- 홈의 일정과 중계도 시즌 조회 결과를 재사용한다. 2주 조회가 시즌 경계를 넘을 때는 기존 기간 조회를 유지한다.

## 확인

- 실제 라리가 2026년 11월 API: HTTP 200, 일반 영상 31개, `source: youtube-uploads`, 판별 지연 안내 없음.
- 실제 화면: 1~12라운드와 날짜별 경기 영상 표시, 경기 점수·대진 표시, 오류 문구 없음.
- 관련 API·일정·라운드·쇼츠 회귀 검증 61개 통과, 프로덕션 빌드와 수정 소스 린트 통과.

공식 구현 참고: [채널 업로드 목록 조회](https://developers.google.com/youtube/v3/guides/implementation/videos#retrieve_a_channels_uploaded_videos).
